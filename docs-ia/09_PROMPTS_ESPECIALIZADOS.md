# Prompts especializados para desarrollo con IA

## Analizar una nueva funcionalidad

```txt
Actúa como arquitecto de software. Analiza esta nueva funcionalidad antes de implementarla. Indica objetivo, archivos afectados, riesgos, dependencias, plan por fases y criterios de aceptación.
```

## Corregir un bug

```txt
Actúa como desarrollador senior. Analiza este bug con enfoque sistemático. Identifica causas probables, archivos implicados, pruebas para reproducirlo y solución mínima segura. No propongas una reescritura completa salvo que sea imprescindible.
```

## Refactorizar código

```txt
Actúa como revisor senior. Refactoriza este código manteniendo exactamente el mismo comportamiento. Mejora legibilidad, separación de responsabilidades y mantenibilidad. Explica cada cambio relevante.
```

## Optimizar rendimiento

```txt
Actúa como experto en rendimiento frontend y backend. Analiza cuellos de botella, renders innecesarios, carga de datos, tamaño de bundle, caché y complejidad. Propón mejoras ordenadas por impacto y riesgo.
```

## Mejorar interfaz

```txt
Actúa como especialista en UX/UI. Mejora esta interfaz manteniendo coherencia visual con la aplicación. Prioriza claridad, jerarquía visual, accesibilidad, uso móvil y reducción de fricción.
```

## Crear tests

```txt
Actúa como especialista en testing. Propón y escribe pruebas para esta funcionalidad. Incluye flujo principal, casos límite, errores esperados y regresiones. Explica cómo ejecutar las pruebas.
```

## Revisar seguridad

```txt
Actúa como auditor de seguridad de aplicaciones web. Revisa este código buscando exposición de secretos, validación insuficiente, inyección, permisos, errores de autenticación y riesgos en dependencias.
```

## Documentar código

```txt
Actúa como technical writer. Documenta esta funcionalidad para que otro desarrollador pueda entenderla, mantenerla y ampliarla. Incluye propósito, uso, estructura, decisiones y ejemplos.
```

## Preparar despliegue

```txt
Actúa como DevOps senior. Revisa si esta aplicación está preparada para despliegue. Comprueba variables de entorno, build, errores, seguridad, rendimiento, logs y pasos de rollback.
```

## Pedir una respuesta más profesional a la IA

```txt
Reformula tu respuesta como un informe técnico profesional. Separa diagnóstico, decisiones, implementación, pruebas, riesgos y próximos pasos.
```
