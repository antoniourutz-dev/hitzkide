# Sistema profesional de desarrollo de aplicaciones con IA

Este paquete define una forma de trabajar con IA para desarrollar aplicaciones de manera ordenada, mantenible y profesional.

## Objetivo

Evitar que la IA trabaje de forma improvisada. Cada petición debe partir de contexto, reglas, arquitectura, tareas concretas, criterios de calidad y validación.

## Archivos incluidos

1. `01_CONTEXTO_DEL_PROYECTO.md`  
   Define qué es la aplicación, a quién sirve, qué tecnologías usa y qué límites tiene.

2. `02_REGLAS_DE_TRABAJO_CON_IA.md`  
   Establece cómo debe comportarse la IA cuando desarrolla, revisa o modifica código.

3. `03_PROMPT_MAESTRO_DESARROLLO.md`  
   Prompt base para iniciar sesiones de desarrollo profesional con IA.

4. `04_PLANTILLA_TAREA.md`  
   Plantilla para pedir nuevas funciones, correcciones o mejoras.

5. `05_REVISION_DE_CODIGO.md`  
   Checklist para revisar calidad, seguridad, rendimiento y mantenibilidad.

6. `06_ARQUITECTURA_Y_DECISIONES.md`  
   Registro de decisiones técnicas importantes.

7. `07_TESTING_Y_VALIDACION.md`  
   Guía para comprobar que los cambios funcionan antes de aceptarlos.

8. `08_FLUJO_DE_TRABAJO.md`  
   Proceso recomendado para trabajar paso a paso con IA.

9. `09_PROMPTS_ESPECIALIZADOS.md`  
   Prompts listos para refactorizar, depurar, optimizar y documentar.

10. `10_CONTROL_DE_CAMBIOS.md`  
   Registro simple de versiones y cambios realizados.

## Cómo usar este sistema

Antes de pedir código a la IA:

1. Actualiza el contexto del proyecto.
2. Describe la tarea con la plantilla.
3. Pide primero análisis y plan.
4. Después pide implementación.
5. Exige pruebas, revisión y explicación de cambios.
6. Registra las decisiones importantes.

La IA debe actuar como un colaborador técnico, no como un generador automático de fragmentos sueltos.
