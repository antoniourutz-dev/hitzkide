## ADR-0001: Estructura inicial del sistema de trabajo con IA

Fecha:

Estado: Aceptada

## Contexto

El desarrollo con IA puede volverse desordenado si no existe contexto, reglas y control de cambios.

## Decisión

Se crea un conjunto de archivos base para guiar el desarrollo profesional con IA.

## Consecuencias positivas

- Mejora la continuidad entre sesiones.
- Reduce errores por falta de contexto.
- Facilita tareas pequeñas y verificables.
- Permite revisar cambios con criterios estables.

## Riesgos

- Requiere mantener los archivos actualizados.
- Si el contexto queda obsoleto, la IA puede tomar malas decisiones.
